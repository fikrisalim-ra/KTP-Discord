Pertanyaan Umum (FAQ)

Cara dapetin User ID nya gimana bang?

Klik kanan aja profile mu trus dipaling bawah ada "Copy user ID". Kalau nggak ada harus aktifin developer mode dulu

Dari mana data KTP Discord ini diambil?

Ini data publik akun Discord (seperti nama, username, foto profil, dan tanggal pembuatan akun dari Snowflake ID) terus diambil sama Professor Mornye dan laporin balik ke web ini pakai n8n.

Aman nggak masukin User ID ke sini?

Aman aja, toh semua orang bisa ambil user ID miliknya sendiri dan orang lain. Ini bukan password atau yang perlu dirahasiakan

Kenapa muncul pesan gagal terhubung ke server?

Pastikan User ID terdiri dari 17–20 digit angka yang valid, dan pastikan server workflow n8n sedang dalam status aktif.

Kenapa buat ni web? Kan dh ada bot Danyaa dan bisa command /ktp?

Ceritanya ini buat latihan atau tahap awal produk skripsi ku aja. Mikirin gimana caranya dari web bisa komunikasi ama bot ku nanti. Trus juga nyoba hosting di Github biar gratis, sebagai gantinya webnya g ada backend dan yang ngurus workflow n8n ku. Ogah bayar double sementara ini gw wok

Ini AI slop ya bang?

Nggih mas, iki AI Slop, kulo isu kemampuan mas 🥀
